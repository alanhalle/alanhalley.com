Privacy Policy

Last updated 17 September 2026

This policy covers the personal software I run under my own Google account, including the tools I refer to collectively as Second Brain. These are single-user tools. I am the only user, and they are not offered to the public.

What the software accesses

Second Brain requests read-only access to my own Gmail account using the gmail.readonly scope. It cannot send, delete, or modify mail. It accesses no other Google service — no Drive, Calendar, or Contacts.

What it does with that access

On a schedule, it reads recent messages in my inbox to sort them into categories and produce a short digest for me to read. Message text may be sent to the Anthropic API for that classification step. Anthropic does not train models on data submitted through its API.

What is stored, and where

  • The digest output is written to a private repository on GitHub that only I can read.
  • Message bodies are not retained beyond the run that processes them.
  • Access credentials are stored as encrypted repository secrets, never in code.

What is not done

No data is sold, rented, or shared with third parties for advertising or any other purpose. There are no analytics or tracking in these tools. No other person has access to the data they read, and no account other than my own is ever accessed.

Correspondents

Mail I receive necessarily contains information about the people who wrote to me. That information is processed only to sort my own inbox, is not retained beyond processing, and is never used to contact anyone, build a profile, or for any purpose beyond my reading of my own mail. If you have written to me and want to know what happened to your message, ask me.

Retention and removal

I can revoke the software's access to my Google account at any time through my Google Account security settings, which immediately stops all access. Generated digests are deleted when I delete them.

This website

alanhalley.com is a static site. It sets no cookies and runs no analytics or advertising scripts. Standard server logs are kept by the host in the ordinary course of serving pages.

Changes

If this policy changes, the revised version will be posted here with a new date.
